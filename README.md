# SOLE. — Footwear Landing Page

A modern, responsive footwear landing page designed to showcase a fictional shoe brand, **SOLE.**

Built using **HTML5 and CSS3**, this project focuses on clean design, intuitive navigation, product presentation, and a seamless browsing experience across desktop, tablet, and mobile devices.

## Live Demo

🌐 **[View Live Website](https://deborahsabaratnam.github.io/sole-footwear-landing-page/)**

## Features

- **Responsive Design** — Optimized layouts for desktop, tablet, and mobile screens.
- **Modern User Interface** — Minimalist design with a soft pastel color palette and clean typography.
- **Lifestyle Banner** — A visually engaging banner with a clear call-to-action.
- **Featured Products** — Product cards displaying shoe images, descriptions, and prices.
- **WhatsApp Inquiry Buttons** — Product inquiry links included as demonstration placeholders.
- **Brand Story** — A dedicated section introducing the fictional brand.
- **Benefits Section** — Highlights comfort, quality, and design.
- **Smooth Navigation** — Section-based navigation for an intuitive browsing experience.
- **Optimized Images** — WebP images used to improve page-loading performance.

## Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/deborahsabaratnam/sole-footwear-landing-page.git
   ```

2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser or use the VS Code Live Server extension.

No additional dependencies or installation are required.
